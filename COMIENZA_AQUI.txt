💡 EJEMPLO ULTRA SIMPLE
═══════════════════════════════════════════════════════════════════════════

En tu Checkout.vue, después de procesar el pago:

    import { usePaymentPages } from '@/composables/usePaymentPages'
    const { goToSuccess, goToFailed } = usePaymentPages()

    if (pago_exitoso) {
        await goToSuccess('TICKET-001', datos_ticket, true)
    } else {
        await goToFailed('ERR-001', 'insufficient_funds')
    }

¡Eso es todo! El usuario verá la landing page correcta automáticamente.
